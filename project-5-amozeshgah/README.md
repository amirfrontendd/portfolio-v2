# 🎓 آکادمی نخبگان — سایت آموزشگاهی

سایت تک‌صفحه‌ای مدرن و شیک برای آموزشگاه/آکادمی، با **حالت شب و روز** و **دو زبانه (فارسی/انگلیسی)**.

## ✨ امکانات

- 🌙☀️ **تغییر تم دارک/لایت** با یک کلیک — انتخاب کاربر در مرورگر ذخیره می‌شود
- 🌐 **دکمه تغییر زبان فا/EN** — ترجمه کامل متن‌ها + تغییر جهت صفحه (RTL/LTR) و فونت
- 🎨 طراحی مدرن: گرادیانت، گلس‌مورفیسم، انیمیشن لودر و شمارنده‌های متحرک آمار
- 📱 کاملاً ریسپانسیو با منوی همبرگری در موبایل
- 🚫 بدون هیچ فریم‌ورک یا کتابخانه‌ای — فقط HTML خالص

## 📁 ساختار فایل‌ها

```
├── index.html   ساختار صفحه
├── style.css    استایل‌ها و تم‌ها
└── script.js    تم، زبان، شمارنده‌ها و منو
```

## 🚀 اجرا

فایل‌ها را کنار هم نگه دارید و `index.html` را در مرورگر باز کنید. همین!

```bash
# یا با یک سرور محلی (اختیاری):
python -m http.server 8000
# سپس http://localhost:8000
```

## 🛠 شخصی‌سازی

| چه چیزی | کجا |
|---|---|
| متن‌های فارسی و انگلیسی | آبجکت `i18n` در `script.js` |
| رنگ‌ها | متغیرهای `:root` و `[data-theme="light"]` در `style.css` |
| دوره‌ها و اساتید | بخش‌های `courses` و `teachers` در `index.html` |
| لوگو و نام آموزشگاه | تگ `logo` و کلید `brand` |
